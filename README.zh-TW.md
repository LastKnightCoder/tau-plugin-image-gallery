# 圖冊

在內文裡插入圖冊，將多張圖片排成一組，支援三種版面配置：

- **橫排**：依圖片比例排成等高的列，適合攝影作品、截圖集。
- **瀑布流**：依欄位錯落排列，適合直式圖片較多的情境。
- **輪播**：一次顯示一張，左右切換。

## 使用方式

1. 在空行輸入 `/`，選擇「圖冊」插入。
2. 點擊「新增圖片到圖冊」，上傳圖片、貼上剪貼簿裡的圖片或輸入圖片連結；拖曳圖片可調整順序。
3. 點選圖冊後，上方的屬性列可切換版面配置、編輯圖片與全螢幕預覽；選取時按 Enter 編輯、空白鍵預覽、Delete 刪除。

圖冊的圓角與陰影預設跟隨「設定 → 外觀」裡的圖片外觀，也可以在編輯視窗裡單獨調整。匯出 Markdown 時每張圖片會匯出為一行圖片連結；匯出 HTML、EPUB 或複製到微信公眾號時會呈現為一組可左右滑動的圖片。
